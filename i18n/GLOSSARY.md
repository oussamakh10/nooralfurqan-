# Translation rules for "نور الفرقان" (Nur al-Furqan), an Islamic learning app (Duolingo style, all ages incl. children)
Audience: general public, beginners and non-Arabic speakers. Tone: friendly, simple, respectful, concise. Mainstream Sunni, no disputed details.
Translate every Arabic string to English AND French, keeping meaning exact and UI strings short (buttons: 1-3 words).
Rules:
- Keep placeholders exactly: digits stay as digits; `{...}` tokens untouched. Keep punctuation style (…, ؟ -> ?). Keep emoji/symbols.
- The mascot is a hoopoe: "الهدهد" -> EN "Hoopoe" / FR "la Huppe". "هدهد" as speaker of lines is the hoopoe.
- Keep "ﷺ" after the Prophet's name; EN: "the Prophet Muhammad ﷺ"; FR: "le Prophète Muhammad ﷺ". Other prophets: "عليه السلام" -> EN "(peace be upon him)" ; FR "(paix sur lui)". Companions: "رضي الله عنه" -> EN "(may Allah be pleased with him)"; FR "(qu'Allah l'agrée)".
- Allah stays "Allah" (EN, FR). Qur'an: EN "Qur'an", FR "Coran". Use these terms (first-time-friendly, Arabic term in parentheses where helpful): prayer (Salah / la prière), ablution (Wudu / les ablutions), purification (Taharah), fasting (Sawm / le jeûne), almsgiving (Zakat), pilgrimage (Hajj / le pèlerinage), Ramadan, Hadith, Sunnah, Seerah (Prophet's biography / la biographie du Prophète), Tafsir (Qur'an commentary / exégèse), Tajweed, Dhikr (remembrance of Allah / invocation), Adhkar, Tasbih, Hasanat (good deeds / bonnes actions), Imam, Surah, Ayah (verse / verset), Juz', Khatma (completing the Qur'an / la lecture complète du Coran), Qibla, Mushaf (Qur'an copy).
- Surah names: standard transliteration, e.g. الفاتحة -> "Al-Fatihah" (FR "Al-Fatiha"), البقرة -> "Al-Baqarah" (FR "Al-Baqara").
- Reciters' names: standard Latin transliteration (same in EN and FR).
- Qur'an verses quoted inside ﴿ ﴾ : give the meaning in quotation marks in the target language using the well-known wording style of Saheeh International (EN) / Hamidullah-style (FR); never invent; if short, translate literally. Hadith quotes: faithful meaning, reference kept: "متفق عليه" -> EN "Agreed upon (Bukhari & Muslim)"; FR "Rapporté par al-Bukhari et Muslim"; "رواه مسلم" -> "Narrated by Muslim"/"Rapporté par Muslim" etc.
- Quiz answers: keep the correct and wrong options parallel in form and length so the answer isn't given away by grammar.
- Ordering-quiz items are short phrases: keep them short.
- Strings that are only an Arabic name/word with no sensible translation: transliterate.
- Do NOT add explanations, do not merge or skip strings. One output pair per input string, same order.
